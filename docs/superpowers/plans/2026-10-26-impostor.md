# Impostor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Offline-PWA für das Partyspiel „Impostor“ mit Fußballern und Vereinen, gespielt mit einem Handy, das reihum weitergegeben wird.

**Architecture:** Reine, getestete Logik (`modes`, `engine`, `settings`, `session`, `state`) ohne UI-Abhängigkeit; `storage` kapselt localStorage; React-Screens sind dünn und werden in `App.tsx` über einen Reducer verdrahtet. Deployment als statische Seite auf GitHub Pages.

**Tech Stack:** Node 22, Vite, React 18, TypeScript (strict), Vitest + jsdom + @testing-library/react, vite-plugin-pwa.

**Spec:** `docs/superpowers/specs/2026-10-26-impostor-design.md`

## Global Constraints

- Sprache der Oberfläche: Deutsch. Feste Texte exakt: „Luca ist dran“ (`{name} ist dran`), „Ich bin {name}“, „Fertig – weitergeben“, „🕵️ Du bist der Impostor“, „{name} beginnt“, „Auflösen“, „Neue Runde“, „Einstellungen“, „Runde abbrechen?“, „Start“.
- Modus-Labels exakt: „⚽ Alle Fußballer“, „🇩🇪 Bundesliga“, „🏆 CL-Legenden“, „🌍 WM-Legenden“, „🏟️ Vereine Bundesliga“, „🌐 Vereine International“. Schwierigkeit: „Leicht“, „Mittel“, „Schwer“.
- Mindestens 3 Spieler; Impostor 1 bis `floor((Spieler − 1) / 2)`.
- Starter zufällig aus **allen** Spielern, Impostor eingeschlossen.
- 50-%-Regel: Wenn mindestens 50 % des Topfs in `used` stehen, wird `used` für diesen Topf vor dem Ziehen geleert. `used` wird pro `poolKey` geführt.
- Kein Hilfswort in v1.0 (`hint` überall `null`, wird nirgends angezeigt).
- Komplett offline nach der Installation; keine Netzwerkzugriffe zur Laufzeit.
- `user-select: none`, `overscroll-behavior: none`, kein Kontextmenü bei langem Drücken; Aufdeck-Karte in der Bildschirmmitte, nicht am unteren Rand.
- Codex (`codex exec`) darf für abgegrenzte Teilaufgaben genutzt werden (markiert mit **Codex**); Ergebnis wird immer von Hand geprüft und gegen die Tests laufen gelassen.

## Review Focus

1. **Namen mit Leerzeichen / Groß-Kleinschreibung** („Luca“ und „ luca “) – müssen getrimmt und als Duplikat erkannt werden → Test in Task 4.
2. **Spielerzahl wird reduziert, gespeicherte Impostor-Anzahl ist jetzt zu hoch** – Einrichtung muss auf das neue Maximum herunterkorrigieren statt einen ungültigen Start zuzulassen → Test in Task 8.
3. **Kaputter oder veralteter localStorage** (ungültiges JSON, unbekannte Phase, Begriffe in `used`, die es im Topf nicht mehr gibt) – App startet trotzdem, ungültiges wird verworfen, fremde `used`-Einträge zählen nicht zur 50-%-Grenze → Tests in Task 3 und Task 6.
4. **Doppeltippen auf „Fertig – weitergeben“** – darf keinen Spieler überspringen; Aktionen, die in der aktuellen Phase nicht gültig sind, werden ignoriert → Test in Task 5.
5. **Zurück-Geste mitten in der Runde** – darf nicht zur vorherigen Karte führen, sondern fragt „Runde abbrechen?“; bei „Nein“ bleibt alles wie es war → Test in Task 10.

### Task 5: Spielablauf (`state.ts`)

**Files:** Create `src/game/state.ts`, Test `tests/game/state.test.ts`

**Interfaces:**
- Consumes: `Round`.
- Produces:
```ts
export type GameState =
  | { phase: "setup" }
  | { phase: "handoff"; round: Round; index: number }
  | { phase: "reveal"; round: Round; index: number; seen: boolean }
  | { phase: "discussion"; round: Round }
  | { phase: "resolution"; round: Round };
export type Action =
  | { type: "start"; round: Round }   // gültig in setup und resolution → handoff(0)
  | { type: "confirm" }               // handoff → reveal(seen=false)
  | { type: "seen" }                  // reveal → seen=true
  | { type: "passOn" }                // reveal mit seen → handoff(index+1) bzw. discussion nach dem letzten
  | { type: "resolve" }               // discussion → resolution
  | { type: "toSetup" };              // aus jeder Phase → setup
export function reducer(state: GameState, action: Action): GameState;
export function restore(saved: GameState): GameState; // reveal → handoff mit gleichem index, sonst unverändert
```
