# Impostor v1.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gruppen mit Kader und Sitzreihenfolge, Statistik (Heute/Allzeit), Auflösung mit „erwischt?“ und „Impostor darf raten“, Regeln-Seite, BVB-Modus und QR-Code zum Teilen.

**Architecture:** Neue reine Module `src/game/groups.ts` (Gruppen-Operationen) und `src/game/stats.ts` (Protokoll → Kennzahlen); Auflösungsschritte als Teil des Zustandsautomaten (überleben Neuladen); Speicherfunktionen in `src/storage.ts`; neue Bildschirme werden in `App.tsx` über einen nicht gespeicherten `view`-Zustand eingeblendet.

**Tech Stack:** wie bisher (Vite, React 18, TypeScript, Vitest); neu: `qrcode` + `@types/qrcode`.

**Spec:** `docs/superpowers/specs/2026-10-26-v1.4-gruppen-statistik-design.md`

## Global Constraints

- Alles offline, nur lokaler Speicher; Schlüssel `impostor:v1:groups`, `impostor:v1:stats:<groupId>`.
- Feste Texte: „Ohne Gruppe“, „+ Neue Gruppe“, „Gruppe bearbeiten“, „+ Neues Mitglied“, „Impostor darf raten“, „Wurde Ben erwischt?“ / „Wurden die Impostor erwischt?“, „Ja“, „Nein“, „Ben darf jetzt das Wort raten“, „Wort aufdecken“, „Hat Ben richtig geraten?“ / „Hat einer richtig geraten?“, „Crew gewinnt 🎯“, „Impostor gewinnt 🕵️“, „Impostor gewinnt trotzdem 🕵️“, „Regeln“, „Statistik“, „App teilen“, „Heute“, „Allzeit“, „Neuer Abend“, „Statistik löschen“, „Link teilen“, „Link kopieren“.
- Bei 0 oder allen Impostorn keine Fragen in der Auflösung (Anzeige wie v1.3).
- „Impostor darf raten“ Standard: an. `groupId` Standard: null.
- Statistik nur mit Gruppe; Kennzahlen über Member-IDs, Anzeige mit aktuellem Namen.
- BVB-Modus: Label „🟡 BVB“, direkt nach „🇩🇪 Bundesliga“, ohne Schwierigkeit, mind. 40 Einträge.
- UI baue ich selbst (frontend-design), bestehender Stil; Codex nur für Daten und die Module aus Task 2/3 nach Test-Vorgabe; jedes Codex-Ergebnis wird von mir gelesen.

## Review Focus

1. **Neuladen mitten in der Auflösung** (z. B. nach „Ja“, vor „Wort aufdecken“) → gleicher Schritt erscheint wieder, Runde wird nicht doppelt in die Statistik geschrieben → Tests in Task 4 und Task 6.
2. **Gelöschte Gruppe ist noch in den Einstellungen gewählt** → Einrichtung fällt auf „Ohne Gruppe“ zurück, kein Absturz → Test in Task 5.
3. **Mitglied nach gespielten Runden umbenannt** → Statistik zeigt den neuen Namen mit alten Werten → Test in Task 3.
4. **Weniger als 3 Mitglieder ausgewählt** → „Start“ gesperrt mit „Mindestens 3 Spieler“ → Test in Task 5.
5. **Gespeicherter Auflösungs-Zustand aus v1.3 (ohne `step`)** → lädt als abgeschlossen („done“), Buttons „Neue Runde“/„Einstellungen“ funktionieren → Test in Task 4.
